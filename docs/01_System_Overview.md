# PCB故障检测系统 - 系统概述

## 系统简介

PCB故障检测系统是一个基于Qt 6.7.3框架开发的C++应用程序，专门用于PCB电路板上电子元件的自动故障检测和诊断。系统采用多线程架构，支持多种硬件设备的同步控制，能够对电阻、电容、电感、二极管和集成电路等元件进行全面的故障分析。

## 核心特性

### 1. 多元件支持
- **电阻器**: 开路、短路、阻值偏差检测
- **电容器**: 开路、短路、容值偏差、高ESR检测
- **电感器**: 开路、短路、感值偏差检测
- **二极管**: 开路、短路、正向压降异常、反向漏电检测
- **集成电路**: 电源引脚、功能引脚完整性检测

### 2. 多设备集成
- **JY5711 (AO设备)**: 模拟输出，用于信号激励
- **JY5322/JY5323 (DAQ设备)**: 数据采集，支持多通道同步采样
- **JY8902 (DMM设备)**: 数字万用表，高精度测量

### 3. 智能诊断算法
- 基于统计分析的故障判断
- 自适应阈值设置
- 多参数综合评估
- 潜在的AI增强诊断（ONNX Runtime支持）

### 4. 用户友好界面
- 直观的Qt图形界面
- 实时状态监控和进度显示
- 批量和单次测试模式
- 详细的测试报告和结果导出

## 工作流程

### 1. 系统初始化
1. 检查硬件设备可用性
2. 启动设备线程池
3. 建立设备通信连接
4. 初始化同步控制器

### 2. 测试执行
1. 加载测试配置文件
2. 创建测试序列
3. 执行多设备同步测量
4. 实时数据采集和处理
5. 故障诊断算法分析

### 3. 结果处理
1. 生成诊断报告
2. 数据可视化展示
3. 结果导出和存储
4. 异常情况记录

## 技术特点

### 多线程安全设计
- 每个硬件设备独立线程管理
- 线程间安全的消息传递机制
- 设备状态实时同步
- 避免界面冻结的异步操作

### 设备同步控制
- 多设备协调工作
- 精确的时序控制
- 同步组管理
- 超时和错误处理

### 模块化架构
- 松耦合的组件设计
- 易于扩展和维护
- 标准化的接口定义
- 灵活的配置管理

## 开发环境

- **开发语言**: C++17
- **GUI框架**: Qt 6.7.3 (Widgets, Core, PrintSupport)
- **构建系统**: QMake
- **编译器**: MSVC (Windows)
- **硬件驱动**: JY设备SDK
- **第三方库**: 
  - QCustomPlot (数据可视化)
  - ONNX Runtime (AI推理)
  - FFTW3 (信号处理)
