# PCB故障检测系统 - 系统概述

## 系统简介

PCB故障检测系统是一个基于Qt 6.7.3框架开发的C++应用程序，专门用于PCB电路板上电子元件的自动故障检测和诊断。系统采用ComponentDiagnosticFramework模块化架构，支持多种硬件设备的同步控制，集成了PCB识别、实时图像分析、接线引导等先进功能。

## 核心特性

### 1. 智能元件诊断 (ComponentDiagnosticFramework)
- **电阻器**: 开路、短路、阻值偏差检测，支持2/4线测量
- **电容器**: 开路、短路、容值偏差、高ESR、漏电流检测
- **电感器**: 开路、短路、感值偏差、DCR、Q因子检测
- **二极管**: 正向压降、反向漏电、击穿特性检测
- **集成电路**: 电源完整性、逻辑功能、引脚连通性检测

### 2. 多设备集成控制
- **JY5711 (AO设备)**: 多波形模拟输出，支持正弦波、方波、三角波等
- **JY5322/JY5323 (DAQ设备)**: 32通道同步数据采集，支持单点/多点/连续模式
- **JY8902 (DMM设备)**: 高精度电阻测量，支持2线/4线模式
- **设备同步控制**: 多设备协调工作，精确时序控制

### 3. PCB智能识别系统
- **实时PCB识别**: 基于SIFT特征匹配的PCB型号识别
- **元件自动检测**: YOLO深度学习模型自动检测PCB元件
- **板卡数据库管理**: PCB模型库，支持增删改查
- **综合分析**: PCB识别+元件检测+故障诊断一体化

### 4. 摄像头集成系统
- **高清摄像头**: 8K分辨率支持，实时图像采集
- **红外温度摄像头**: 实时温度监测，热点检测，温度报警
- **图像处理**: OpenCV图像处理，实时标注显示
- **数据采集**: 图像+温度数据同步采集存储

### 5. 智能接线引导 (WiringGuide)
- **自动端口分配**: 根据测试需求自动分配最优端口
- **可视化接线指导**: 图形化接线引导界面
- **资源管理**: 端口资源冲突检测和自动调度
- **任务管理**: 测试任务生成和执行管理

### 6. 用户友好界面
- **模块化界面**: 设备状态、单元测试、批量测试、结果分析
- **实时监控**: 设备状态、测试进度、温度监控
- **数据可视化**: QCustomPlot图表、红外热图显示
- **报告导出**: 详细测试报告和数据导出

## 工作流程

### 1. 系统初始化
1. 检查硬件设备可用性 (JY5711/JY5322/JY5323/JY8902)
2. 启动设备线程池和同步控制器
3. 初始化摄像头系统 (HD摄像头 + 红外摄像头)
4. 加载PCB模型数据库和YOLO检测模型
5. 初始化接线引导系统

### 2. PCB检测与识别
1. 高清摄像头实时图像采集
2. SIFT特征匹配进行PCB型号识别
3. YOLO模型自动检测PCB元件
4. 生成元件列表和坐标信息
5. 红外摄像头温度监测

### 3. 自动接线引导
1. 根据检测到的元件生成测试任务
2. 自动分析端口需求和资源冲突
3. 生成最优接线方案
4. 可视化接线引导界面
5. 验证接线连通性

### 4. 智能故障诊断
1. ComponentDiagnosticFramework执行元件诊断
2. 多设备同步测量和数据采集
3. 专用算法分析各类元件特性
4. 实时温度监控和热点检测
5. 综合健康度评估

### 5. 结果处理与报告
1. 生成详细诊断报告 (文本/图表/图像)
2. 数据可视化展示 (QCustomPlot + 红外热图)
3. 结果导出 (CSV/JSON/PDF)
4. 历史数据管理和统计分析

## 技术特点

### ComponentDiagnosticFramework架构
- **模块化设计**: 每种元件独立诊断器
- **统一接口**: 标准化的诊断流程和数据格式
- **异步处理**: 支持单个/批量/并发诊断
- **扩展性**: 易于添加新的元件类型和算法

### 多线程安全设计
- **设备线程隔离**: 每个硬件设备独立线程管理
- **同步控制器**: DeviceSyncController协调多设备操作
- **线程安全**: QMutex保护的数据访问
- **异步操作**: 避免界面冻结，支持任务取消

### AI增强功能
- **深度学习**: YOLO v11模型自动检测PCB元件
- **特征匹配**: SIFT算法实现PCB型号识别
- **ONNX Runtime**: 支持ONNX格式AI模型推理
- **实时处理**: 摄像头实时图像AI分析

### 数据管理系统
- **SQLite数据库**: PCB模型、检测记录、测试历史
- **图像管理**: 自动图像存储和标注
- **配置管理**: 测试参数、设备配置持久化
- **导入导出**: 支持多种格式的数据交换

## 开发环境

- **开发语言**: C++17
- **GUI框架**: Qt 6.7.3 (Widgets, Core, Concurrent, OpenGL)
- **构建系统**: QMake
- **编译器**: MSVC 2022 (Windows x64)
- **图像处理**: OpenCV 4.11.0
- **AI推理**: ONNX Runtime 1.16.0
- **数据可视化**: QCustomPlot 2.1.1
- **硬件驱动**: JYTEK SDK (JY5711/JY5320/JY8902)
- **信号处理**: FFTW3
